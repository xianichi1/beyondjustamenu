# beyond just a menu

An interactive mobile-first web project exploring food consumption, cultural commodification, and anti-Asian solidarity in Toronto.

## Overview
What begins as an enticing promotional boba coupon gradually reveals a deeper critical narrative on how cultural cuisine is enthusiastically consumed while the workers and communities behind it face systemic discrimination.

## Project Structure (For Web / GitHub Pages)
This repository is built using clean, pure HTML5, CSS3, and Vanilla JavaScript:

- `index.html`: Core document structure, interactive screens, and resource modals.
- `style.css`: Custom mobile-frame styling, typography, and CSS animations.
- `script.js`: Interactive state transitions, tear-away voucher mechanics, and modal controls.
- `W3SCHOOLS_CITATIONS.md`: Comprehensive breakdown of web techniques and W3Schools references used in this project.

## How to Run
Simply open `index.html` in any web browser or host directly via GitHub Pages. No dependencies or build steps required.
